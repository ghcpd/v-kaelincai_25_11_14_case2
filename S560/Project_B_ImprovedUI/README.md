# Project B — Improved UI (Card-based)

This project contains the improved card layout with spacing, button consistency, hover states, and ARIA attributes.

Quick start:
1. From repo root, run: ./setup.sh
2. Run tests: ./Project_B_ImprovedUI/run_tests.sh

Artifacts:
- screenshots/ — improved screenshots
- results/ — results_post.json and per-check JSON files
- logs/ — log_post.txt

Test expectations: The improved UI has >=16px card padding, unified buttons, accessible focus outlines, and consistent icon sizes.
