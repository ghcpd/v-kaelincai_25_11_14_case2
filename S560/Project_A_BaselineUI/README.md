# Project A — Baseline UI (Dense List)

This project contains a dense task list UI (baseline) and automated checks for visual rendering, CSS assertions, and accessibility.

Quick start:
1. From repo root, run: ./setup.sh
2. In PowerShell or bash: ./Project_A_BaselineUI/run_tests.sh

Artifacts:
- screenshots/ — baseline screenshots
- results/ — results_pre.json and per-check JSON files
- logs/ — log_pre.txt

Test expectations: The baseline is intentionally dense with small paddings, inconsistent icon sizes, and inconsistent button colors.
