# UI/UX Redesign - Dense List to Improved Cards

This repository contains two independent, fully reproducible projects demonstrating a UI redesign: a dense baseline task list and an improved card-based UI.

Use run_all.sh to run the complete test pipeline and generate a comparison report with screenshots, visual diffs, results, and logs.

Files created and how to use them:
- run_all.sh — runs baseline & improved tests and aggregates a compare_report.md
- setup.sh — installs Python packages and Playwright browsers
- generate_diffs.py — creates visual diffs for key screenshots
- Project_A_BaselineUI/ — dense baseline UI + tests
- Project_B_ImprovedUI/ — cleaned-up, accessible improved UI + tests

Acceptance criteria examples:
- Card padding >= 16px (improved)
- Title font-size >= 18px (improved)
- Buttons follow consistent styling with unified color and hover behavior
- Icon sizes are consistent across tasks
- Focus states are visible and a11y-related ARIA attributes present
- Contrast ratio >= 4.5:1 for body text and core content

Pitfalls & recommendations:
- Visual diffs are resolution and OS dependent; consider tolerance thresholds.
- Fonts and rendering may vary; consistent font bundling helps.
- Axe finds potential issues but manual review is recommended.

For details, see the project README files in each folder and the compare_report.md generated by running run_all.
